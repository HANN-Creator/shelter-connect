# B95 생성 문구 길이 초과 자동 복구

> **과거 변경·검증 기록.** 현재 일반 작업은 [서버 에셋 기준](asset-pipeline-current.md)의 경고 정책을 따른다. 아래 차단·보완 설명은 당시 정책 또는 기존 작업의 호환 경로에 해당한다.

[노션 카드](https://app.notion.com/p/3f65b2d1a55f805697aefc7e99160034)

B94 실제 세 마리 검증 중 갈색 강아지의 앞 IDLE은 STATIC_IDLE로 검수를
통과했으나, 북쪽 IDLE 생성 문장이 1000자 제한을 10·13·41자 넘어서
`LESSON_PROMPT_INVALID`로 중단됐다. 북쪽 PixelLab 제출 이전 실패였다.

`complete-prompt-compact-v4`는 기존 3회 AI 형식 수정까지 끝난 응답 중,
길이만 초과한 완전한 문장에 한해 문장부호 뒤·영문자 앞의 ASCII 공백을
제거한다. 최신 응답부터 한도 안에 드는 초안을 찾는다. 단어·숫자·부정·비교·
조건을 삭제하거나 치환하지 않는다. 단어 사이 공백과 숫자 앞 구분 공백도
유지한다. 실제 1013자 초안은 974자가 되고, 마지막 1041자 초안은 1002자라
사용하지 않는다.

형식에 맞더라도 독립 Luna 검수가 원래 기본 지시와 모든 학습 규칙의 의미를
확인해야 READY가 된다. 검수 실패는 기존 유한 재작성 절차를 따르고, 끝까지
일치하지 않으면 이미지 제출을 막는다. 정상 길이 문장, 다른 형식 오류,
잘린 문장, URL, 전송 결과를 모르는 요청은 이 복구 대상이 아니다.

원본 3회 응답, 선택한 차수, 변환 버전, 전후 길이·해시·최종 문구를 기존
`styled_lesson_prompts.history`에 보존한다. 최초 생성과 보완 작성 모두 같은
경로를 사용한다. 원래 규칙 확인·권한·작업 잠금·문구 해시 검사를 유지한다.

기존 담당자용 `prompt-resume`의 구버전 허용 목록에 v3를 추가한다. 명시적
재개 요청, 실패 위치·원본 해시·규칙 해시 일치, 이전 PixelLab 제출 없음,
동일 버전 중복 재개 금지 등 기존 검사를 그대로 거친다. 배포나 병합만으로
실패했던 원격 작업을 자동 재개하거나 승인하지 않는다.

API 구조, 환경변수, DB 마이그레이션(V24), 보완 예산, 그림체, 승인 이미지,
공유 품질 규칙 v41은 바뀌지 않는다. 실제 재현 자료와 실행 가능한 회귀
검사는 `backend/scripts/fixtures/prompt-spacing-v4`에 있다. 실제 이미지 생성·
최종 승인·앱 재생 통과와 문장 복구 검증은 별도 결과로 기록한다.

실제 Luna 재검사에서 길이 복구 이후 팔레트·머리 고정 조건이 순차적으로
누락되는 것도 확인했다. 재작성은 이미 확인된 문장을 가능한 한 유지하고,
지적된 빠진 조건과 원문의 수식어를 명시적으로 복원하도록 한다. 검수는
한 번에 모든 기본 조건과 규칙을 확인하도록 명확히 했다. 의미 검수의
허용 기준이나 재시도 횟수는 낮추거나 늘리지 않았다. 첫 실제 검사의
실패 응답도 `semantic-feedback.json`에 남긴다.

실제 최종 Luna 검증은 성공했다. 원래 1013자 문장을 974자로 공백 정리한 뒤,
누락된 팔레트를 검출하고 952자로 재작성했다. 이어 방향 조건의 모든 프레임
범위를 검출해 901자로 재작성한 결과, 기본 조건 전체와 학습 규칙 4개가
모두 보존됐다는 독립 판정을 받았다. 실제 모델 응답 5회이며 기존 형식 3회·
의미 3회 상한 안에서 처리했다. 이전 두 실패 실행과 최종 성공 실행을 모두
보존한다. 이 결과는 문구 자동 복구의 실제 검증이며 새 이미지 생성이나
배포된 작업의 최종 승인 결과를 뜻하지 않는다.
