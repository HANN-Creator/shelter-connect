# B-78 무늬 경고의 중복 외형 불일치 차단 수정

노션: https://app.notion.com/p/3f45b2d1a55f809f8951d700d20ddb70

브랜치: `backend/b-78-coat-identity-warning`. 선행: B-77 / PR90 / main `511fe5b4b8a8fed2a1fd27ed914b5dc6a16c7b2f`.

## 실제 실패

B-77 배포 후 기존 작업 `2896c6d7-4809-4275-9e09-43ec4c8ace9c`(공공 동물 `448536202600925`)을 새 v32 규칙으로 재검수했다. 응답의 규칙 SHA는 `ef1ee356d1dc11b722805a74063137c2d3c49d6c05d9ec67e8685754ecfc3d62`였으며 꼬리는 PASS였다. 정면의 일반 검수는 `COAT_MISMATCH`와 `identityMatches=false`를 함께 반환했다. 독립 무늬 검수는 PRESERVED였으므로 무늬 코드는 경고로 전환됐지만, 남은 false 값이 전역 `SEED_IDENTITY`를 다시 만들었다.

`backend/scripts/fixtures/coat-identity-v33/deployed-review.json`은 이 실패 응답 그대로이며 통과 결과로 덮어쓰지 않는다. 사진 및 4방향 원본 SHA, 입력 바인딩과 독립 관찰의 출처는 `evidence.json`에 기록한다. PixelLab 제출 1회, 보완 0회, 기존 12모션 PENDING, 비공개 상태를 유지했다. 임시 STAFF 소속과 로그인은 검수 뒤 해제했다.

## 변경

기존 독립 무늬 검수 호출에 `nonCoatIdentity`(판정·확신도·시각 근거)를 추가한다. 귀 모양, 주둥이 윤곽, 체형, 털 길이를 색·무늬·명암과 분리해서 관찰한다. 별도 AI 호출을 추가하지 않는다.

무늬 이슈와 함께 종합 외형 값이 false인 방향에 한해, 독립 관찰이 PRESERVED이고 확신도가 0.75 이상이며 원래 명시적 `SEED_IDENTITY`가 없으면 종합 값을 정상화한다. 원래 응답과 false 값, 독립 근거와 정상화 사유는 모두 보존한다. 확정된 큰 무늬 누락은 계속 별도 결함으로 남는다. 다른 개체의 외형, 잘림, 눈 가독성, 방향, 꼬리와 구조 결함을 이 과정에서 제거하지 않는다.

명시적 외형 결함과 독립 판단이 충돌하거나 별도 외형 근거가 불확실하면 계속 보류한다. 이때 비용을 쓰는 이미지 보완 및 결함 학습을 시작하지 않는다. 확정된 별도 외형 불일치의 보완 지시에는 무늬 문장이 아니라 해당 외형 근거를 사용한다.

그림체에 대한 `EYE_STYLE`과 `STYLE_DRIFT`는 동일한 미관 경고로 정규화한다. 실제 `eyesReadable=false` 또는 `EYE_READABILITY`는 차단된다. 공통 v33 검수 규칙을 최초 생성 및 보완 검수가 함께 사용한다.

규칙 버전: `sprite-regressions-2026-10-10-v33`.

규칙 SHA: `a8cc43d4e68ef37b8a938f3ca9c5ec445b3de8fc7eb807cc05a65dd784e5b882`.

API 경로·DB 스키마·운영 환경변수 변경 없음. DB V23 유지. 원본 이미지, 그림체, 생성/보완 예산, 이전 검수·승인 이력은 변경하지 않는다.

## 검증 범위

- 실제 원본 사진과 도트에 Luna 독립 검수 1회: 무늬 PRESERVED, 별도 외형 PRESERVED(0.86). 기존 도트를 편집하거나 새로 생성하지 않았다. 해당 실제 관찰은 `independent-observation.json`에 보존한다.
- 실패한 일반 검수와 기존 통과 꼬리 관찰, 새 독립 관찰을 실제 서버 검수 코드에 재생한 BASE 결과 PASS. 이것은 모든 AI 호출을 새로 수행한 전체 실검수 또는 배포 서버 승인이 아니다.
- 합성 관찰 회귀: 정상 외형만 false 정상화, 명시적 불일치/불확실/낮은 확신도/잘못된 응답 차단, 무늬 누락과 다른 결함 보존, 스타일 코드 별칭 경고, 원본 응답 불변, 보완 지시에 별도 외형 근거 사용.
- PostgreSQL 회귀: 실제 원본 도트와 실패 일반 검수·꼬리 관찰, 합성 독립 판단을 생산 검수 및 워커로 재생한다. 무늬 경고는 SYSTEM 승인 및 12모션 저장·공개 manifest까지 연결되고 유료 보완/부정 학습을 시작하지 않아야 한다. 별도 외형 UNCERTAIN은 기본 도트에서 멈추고 모션 생성·공개·학습을 막아야 한다. 모션 공급자/검수는 합성 응답이며 실제 모션 품질 검증으로 보고하지 않는다.
