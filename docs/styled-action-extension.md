# B-104 누락된 행동만 추가

2026-10-17 배치의 1·5·13번은 ‘사나움 / 사납고 공격적임’ 기록이 있지만 경고 행동 기능이 생기기 전에 기본 3개 동작으로 완료됐다. 행동 설정을 바꾸고 일반 생성 API를 다시 호출하면 기준 도트부터 새로 구매하므로, 승인된 비공개 작업에 누락 동작만 추가하는 별도 경로를 사용한다.

## 요청

`POST /v1/shelter-admin/dogs/{dogId}/styled-assets/{jobId}/action-extension`

```json
{
  "requestId": "클라이언트가 보관한 UUID",
  "note": "기존 도트와 완성된 시트를 보존하고 명시된 특징의 누락 행동만 추가한다.",
  "expectedBehaviorRevision": 4,
  "expectedActionPlan": ["BASE", "IDLE", "WALK", "SIT"],
  "expectedSeedHashes": {"south": "64자리 해시", "north": "64자리 해시", "west": "64자리 해시", "east": "64자리 해시"}
}
```

- 같은 보호소의 쓰기 권한, 사진 사용·파생·PixelLab 권한, 비보관 상태를 다시 확인한다.
- 비공개 강아지의 자동 승인된 `WARN_ONLY` 작업만 허용한다. 공개 작업을 재개해서 앱에서 잠시 사라지게 만들지 않는다.
- 현재 확인된 행동 revision과 원래 행동 목록·4방향 기준 도트 해시를 대조한다. 근거가 철회됐거나 DRAFT이면 거절한다.
- 새 계획이 기존 행동의 상위 집합일 때만 허용한다. 완료된 행은 업데이트하지 않고, 없는 행동의 4방향 행만 맨 뒤에 추가한다.
- 기존 사진 분석, PixelLab 접수 이력, 결과 PNG, 검수 기록, seed 승인, 규칙 및 스타일을 유지한다. DB migration과 환경변수 추가는 없다.
- 이전 행동 계획·승인 및 요청자·시각은 `qualityPolicy.actionExtensions`에 보존한다. 같은 requestId와 본문은 같은 작업을 반환하며, 변조된 재전송은 409다.
- 같은 job이 `QUEUED`로 바뀌며 추가 행이 완료된 후 전체 묶음을 다시 자동 승인한다. 경고를 통과 판정으로 바꾸지 않으며, 추가 시각 경고도 기록만 한다.
- 기본 도트나 기존 동작은 재생성하지 않는다. 세 마리에 `GROWL`만 추가하면 유료 생성 요청은 최대 3 × 4 = 12건이며, 공급자가 거절하거나 응답이 불확실한 요청을 별도 작업으로 우회하지 않는다.

일반 생성 API의 선택키는 이 추가 API의 멱등키가 아니다. 기존 작업을 확장하는 클라이언트는 jobId와 requestId를 저장하고 이 경로를 재사용한다.

## 완료 확인

같은 job ID, 13 → 17개 단계, 앞 13개 단계의 전체 결과·검수 및 기존 PNG 해시가 동일하고, 새 유료 호출은 GROWL 4방향뿐인지 확인한다. 실제 배치의 스냅샷과 승인 전후 해시는 로컬 `production-batch-50-2026-10-17/mini-pc-resume`에 보존한다. 로컬/CI 테스트는 실제 공급자 이미지 결과를 대신하지 않는다.

노션 연결 도구가 없어 외부 카드 미동기화. PR 및 실서버 결과는 검증 후 기록한다.
