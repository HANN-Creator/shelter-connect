# 강아지별 스프라이트 아틀라스

`GET /v1/dogs/{dogId}/assets`는 승인된 styled 에셋에 대해 기본적으로 강아지 한 마리의 BASE 4방향과 모든 행동·방향 시트를 한 PNG로 묶어 제공한다. 이전 응답이 필요한 클라이언트는 `?atlas=false`를 사용할 수 있다. 기존 비 styled 에셋 응답은 변하지 않는다.

- `spriteAtlas.url`: 60초 유효한 비공개 저장소 서명 URL. 모든 `mapDirections[*][*].spritesheetUrl`과 `animations[*].spritesheetUrl`이 이 URL을 공유한다.
- 각 `frames[*].x/y/width/height`는 아틀라스 안의 절대 픽셀 좌표다. 프론트는 기존처럼 좌표로 자르면 된다. 프레임 수·시간·행동·방향은 바뀌지 않는다.
- 통합 응답에서 clip의 `sha256`은 URL이 가리키는 아틀라스 PNG의 해시다. 원래 행동 시트의 해시는 `sourceSha256`으로 보존한다. `spriteAtlas.sourceFingerprint`는 원본 목록의 내용 주소이며 PNG 해시가 아니다.
- `spriteAtlas.baseFrames`에는 BASE의 4방향 좌표가 있다. 기존 `baseUrl`은 호환성을 위해 원래 단일 정면 이미지 URL을 유지한다.
- 원본 시트와 DB의 생성·검수 기록은 그대로 둔다. 서버가 첫 공개 조회에 저장된 원본의 SHA-256과 크기를 검증하고 무손실 PNG를 비공개 에셋 저장소에 한 번 기록한다. 이후에는 입력 해시로 정한 동일한 키를 재사용한다. 입력 시트가 달라지면 새 키가 만들어진다.
- 아틀라스 생성이 실패하면 기존 개별 시트 응답으로 돌아가 승인된 강아지의 조회를 유지한다. `spriteAtlas`가 없으면 프론트는 기존 URL을 사용한다.

이 변경은 앱의 이미지 다운로드 요청을 줄인다. PixelLab에 행동·방향을 생성하도록 보내는 요청 수와 생성 시간은 바뀌지 않는다. 데이터베이스 마이그레이션은 필요 없다. 기존 단계별 저장 기록이 아틀라스의 원본 목록이며, 합친 PNG는 비공개 에셋 저장소에 저장된다.
