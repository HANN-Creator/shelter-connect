# 서버 에셋 파이프라인 현재 기준

기준: B98의 경고 정책, B99의 코드·PR 정리. 과거 개별 장애 문서는 당시 원인과 호환 동작 기록이다.
[전체 PR 대조표](pr-consolidation-2026-10-12.md)에서 변경 목적과 종료한 실험을 확인한다.

## 일반 작업

1. 허가된 원본 사진과 특징에서 4방향 기본 도트를 생성하고 비공개 파일 저장소에 저장한다.
2. 기본 행동인 쉬기·걷기·앉기와 특징에 근거해 선택된 추가 행동을 방향별로 생성한다.
3. 기본 도트 4방향과 동작 원본 9프레임을 한 번씩 관찰한다. 의심되는 부분이나 관찰 실패는 경고로 기록한다.
4. 이미지와 입력·권한·저장 연결이 유효하고 필요한 행동이 완성되면 서버가 승인한다. 프론트는 저장된 결과를 조회한다.

`ASSET_VISUAL_WARNINGS_ONLY=true`가 새 일반 작업의 기본값이다. 시각 지적 때문에 유료 편집·재생성·반복 판정을 하지 않는다.
관찰 결과의 `passed=false`도 그대로 보관하며, 이를 엄격 품질 검수 통과라고 바꾸어 기록하지 않는다.
파일 손상·허가 철회·전송 불가능한 문구·공급자/저장 오류는 실제 작업 실패로 남는다.

## 같은 기능처럼 보이는 코드의 역할

| 경로 | 역할 | 언제 사용하나 |
| --- | --- | --- |
| `StyledAssetPolicy` | 작업 생성/호환 정책의 유일한 조립 위치 | 새 요청, 명시적 이전 정책 재검수 |
| `StyledLessonPromptComposer` | 전체 원본 규칙의 문구 작성·저장·관찰 | 최초 생성과 기존 보완 요청 모두, 정책에 따른 의미 검사만 분기 |
| `StyledAssetWorker` + `StyledVisualWarningAgent` | native32/40 생성·저장과 경고 1회 기록 | 현재 일반 작업 |
| `StyledQualityAgent` + `StyledSeedQualityAgent` + 기존 복구 클래스 | 과거 차단 정책과 저장 작업의 검수·복구, 명시적 엄격 모드 | 기존 작업 또는 명시적으로 엄격 모드를 선택한 새 작업 |
| `AssetWorker` / 하네스 | 초기 파이프라인과 기존 에셋 계약 | 이전 작업·이전 manifest |
| `scripts/styled_dog` | 직접 실행하는 생성·비교·회귀 도구 | CLI를 명시적으로 실행할 때 |

이전 검수 코드가 남아 있다는 사실이 현재 경고 작업에서 모두 호출된다는 뜻은 아니다.
기존 DB 작업에는 정책이 고정돼 있어, 새 기본 설정으로 이전 모든 작업을 자동 변환하지 않는다.

## 저장·승인과 검토

- DB V24: 작업 상태, 특징·행동 계획, 파일 위치·해시, 관찰 결과, 경고, 비용 영수증과 이전 시도를 보관한다.
- PNG는 비공개 Storage에 저장한다. DB에 PNG 원본 바이너리를 넣는 방식이 아니다.
- 완성된 공개 팩: `GET /v1/dogs/{dogId}/assets`. 경고가 있어도 기존 좌표로 재생할 수 있다.
- 담당자 경고 이미지: `GET /v1/shelter-admin/dogs/{dogId}/styled-assets/{jobId}/warnings`.
- 기존 미승인 작업 전환: `POST /v1/shelter-admin/dogs/{dogId}/styled-assets/{jobId}/visual-warnings`.
  권한·해시·과거 전송 상태를 검사하고 확정 저장 이미지를 재사용한다.
- 경고 자체를 새로운 확정 결함 학습으로 승격하지 않는다. 이미 활성화된 원본 학습 규칙은 최초 생성에도 사용한다.
- 자세한 전환 조건·응답: [시각 경고 명세](visual-quality-warnings.md).
- 프론트 방향·행동·재생 계약: [행동 재생 명세](dog-action-playback-spec.md).

## 검증과 배포 구분

PR 검사에는 단위·PostgreSQL 회귀 검사, 패키징과 컨테이너 준비 상태 확인이 포함된다.
모의 AI를 사용하는 검사는 코드 동작의 근거이며 실제 강아지 그림 품질 통과를 뜻하지 않는다.
새 버전의 실서버 생성·공개·앱 재생은 각 배포 후 별도로 확인한다.
