## 변경 동작

기존에는 한 방향의 털무늬 관찰 충돌이 네 방향 전체의 보완을 막았다.
기본 도트의 그림체 선호·불확실한 무늬 표현·다른 항목이 모두 통과한 낮은 종합 확신도는
`qualityWarnings`에 남긴다. 원래 AI 응답은 `coatEvidence.originalPropertyReview`와 상세 관찰에 유지된다.
경고는 승인 차단이나 유료 보완 대상이 아니다. 실질적으로 없는 큰 무늬, 잘못된 방향,
읽을 수 없는 눈, 꼬리 누락·잘림은 계속 차단한다. **꼬리 등 구조의 불확실성은 미관 경고로 바꾸지 않는다.**

애니메이션에서 명암·색 변화만 애매하면 `PALETTE_UNCERTAIN` 경고로 남긴다.
그 외 항목은 기존 독립 관찰과 전체 9프레임 검사를 유지한다. 두 관찰이 모두 명확한 색 깜빡임을
보고하면 여전히 결함이다. 원본 후보의 승인에도 같은 경고 예외만 적용하며 다른 불확실성,
잘림, 원본·규칙 해시 불일치를 허용하지 않는다. 첫 관찰에서 palette만 UNCERTAIN인 경우에는
추가 검수 비용을 쓰지 않는다.

확정 결함이 있는 방향만 선택 보완한다. 보완 프롬프트는 그 방향의 결함 코드와 근거로
다시 구성하여 다른 방향의 미관 경고를 재생성 지시로 전달하지 않는다.
모든 결함 코드는 유지하고 서술 인용만 길이를 제한한다. 영향받지 않은 방향의 PNG는 그대로 보존한다.
기존 보완 횟수·사용량 한도와 사진 권한 검사는 그대로 유지한다.

경고가 포함된 검수는 작업 이력에 남지만, 전체 이미지를 정답/오답으로 학습하는 예시에는 넣지 않는다.
현재 학습 예시가 방향별 작은 영역이 아닌 전체 이미지 단위이므로, 경고와 확정 결함이 섞인
보고서 역시 학습에서 제외한다. 확정 결함의 보완은 실행할 수 있다. 이는 모델 자체를 재학습하는 기능이 아니라
검증된 프롬프트 규칙을 재사용하는 기능이다.

## 같은 실제 이미지 확인

같은 배포 작업 `2896c6d7-4809-4275-9e09-43ec4c8ace9c`의 사진과 네 방향 PNG를 변경 없이 검수했다.

| 원격 작업 승인·공개 | 이 로컬 검증에서 수행하지 않음 |

새 기준에서 한 번 실행한 실제 검수 영수증은 `backend/scripts/fixtures/aesthetic-warnings-v32/`에
저장했다. 이전 실패가 사라진 것이 아니라 서로 다른 규칙의 실제 관찰을 모두 보존한 것이다.
실제 AI의 일관성을 모든 강아지에 대해 보장하는 근거로 사용하지 않는다.
원본 사진과 비밀 연결 정보는 커밋하지 않는다.

## 검증과 적용 경계

회귀 검사는 v31의 실제 혼합 판정을 재현하여 정면 경고가 양옆의 확정 보완을 막지 않는지,
원본 PNG와 이전 판정을 유지하는지 확인한다. 별도 합성 응답으로 구조 결함·깨진 응답 차단,
프롬프트 최대 길이, 색 경고와 확정 깜빡임 구분, 경고 학습 제외를 검증한다.
DB 통합 검사에서는 경고 이력 보존 → 유료 보완 없음 → 시스템 자동 승인 → 공개 조회를 확인한다.
합성 응답의 승인 검사는 실제 생성·이미지 품질 검사로 집계하지 않는다.

API 경로·DB 마이그레이션·환경변수 변경 없음. 기존 검수 JSON에 `aestheticPolicy`와
`qualityWarnings`가 추가되며 DB V23을 유지한다. 새 생성·재검수·보완 검수가 같은 정책과 규칙 해시를 사용한다.
승인된 기존 팩은 변경하지 않고, 보류된 작업은 정상 재검수/재개 API로 이어간다.
B-76과 함께 검증하고 두 PR을 병합한 후 한 번 배포한다.
배포 서버의 해당 작업 승인과 12모션·앱 재생은 별도로 남아 있다.
