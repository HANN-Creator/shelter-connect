# 이미지 생성 업체 비교 기록

아래는 업체를 정하기 전의 시험 기록이다. 최종 선택과 구현은 [에셋 생성 API](dog-asset-generation.md)를 참고한다.

## 첫 사진 변환 시험 · 2026-09-23

- 사용자가 제공한 강아지 사진 한 장으로 OpenAI Images API를 실제 호출했다. 설치된 imagegen CLI를 사용했다.
- 실행 모델은 `gpt-image-2`, 중간 화질, 1024×1024, 출력 한 장이다. 앞서 접근 확인만 했던 `gpt-image-2.5-sunburst`와 구분한다.
- 이미지 생성 시간은 40.5초였다. 원본은 단색 배경으로 생성하고 로컬에서 배경과 가장자리 잔색을 제거했다. API에서 투명 배경을 직접 받은 결과는 아니다.
- 결과를 64×64 RGBA PNG로 정리했다. 실제 캐릭터 영역은 `(6,16)~(58,60)`, 기준점은 `(32,60)`이다. 네 발과 황갈색 털·검은 주둥이·접힌 귀·밝은 발끝·짙은 꼬리 끝을 시각적으로 확인했다.
- 햇살 운동장에 합성한 정지 미리보기를 만들었다. 아직 RN 실행이나 애니메이션 검증은 하지 않았다.
- 로컬 결과: `output/imagegen/tan-puppy-v1/`. `dog-base-64.png`는 원본 크기, `dog-base-512.png`는 확대 PNG, `dog-base-preview.png`는 배경 있는 미리보기, `dog-in-sunny-meadow.png`는 맵 합성이다. 프롬프트와 생성 기록도 같은 폴더에 있다.
- 공식 문서의 해당 설정 출력 예상 비용은 $0.053이다. 입력 비용이 별도로 붙고, CLI에서 실제 토큰 사용량·청구액을 보존하지 않으므로 이 값을 실청구액으로 표기하지 않는다.
- 입력 사진과 생성 시험 결과는 Git에서 제외했다. Supabase나 공개 앱에 등록하지 않았다.

공식 문서 확인일: 2026-09-23. 실제 청구액, 8종 동작 품질과 전체 생성 비용은 아직 확인하지 않았다.

## PixelLab 비교 시험 · 2026-09-23

같은 사진으로 PixelLab 결과도 비교한다. OpenAI 결과물을 입력으로 쓰지 않고, 사용자가 제공한 원본 사진을 비율을 유지해 847×1024로 줄여 외형 참고 자료로 사용한다.

- `POST /v2/generate-image-v2`를 한 번 호출해 64×64 투명 배경 후보 16장을 받았다. 눈을 뜨고 네 발로 서 있는 11번 후보를 골랐다. 황갈색 털, 검은 주둥이, 접힌 귀, 밝은 발끝과 짙은 꼬리 끝을 확인했다. 오른쪽 3/4 방향이다.
- 비율을 바꾸지 않고 기준 캐릭터를 오른쪽 2px·위로 3px 옮겨 발 기준선을 y=60에 맞췄다. 잘린 픽셀은 없다.
- 같은 캐릭터로 `POST /v2/animate-with-text-v3`를 동작별 한 번씩 호출했다. WALK·TAIL_WAG·SIT 모두 완료됐다. 각각 8프레임을 요청했지만 실제 반환은 9장이므로, 실제 결과에 맞춰 동작별 9프레임을 보존했다.
- 첫 프레임은 원본 기준 캐릭터와 화면상 픽셀이 동일했다. 전달 파일에서는 첫 프레임 바이트도 기준 PNG와 맞췄다. WALK의 두 프레임은 발 기준선이 2px 높아 아래로 2px 정렬했다. 공통 확대 비율은 1이며 프레임마다 크기를 바꾸지 않았다.
- WALK는 프레임당 125ms, TAIL_WAG는 160ms로 반복한다. SIT는 125ms로 한 번 재생하고 마지막 앉은 자세를 유지한다. GIF 묶음의 SIT 반복은 비교 미리보기용이며 실제 재생 정보는 `loop: false`다.
- 투명 프레임 27장, 동작별 576×64 스프라이트 시트, `manifest.json`, 프롬프트, 설명과 단독 실행 HTML을 프론트 전달 ZIP으로 묶었다. 결과 위치는 Git에서 제외한 `output/imagegen/pixellab-tan-puppy-v1/`이다.
- 브라우저에서 걷기 프레임 진행, 동작 전환, 일시정지, SIT 마지막 자세 유지, 390px 화면의 가로 넘침 없음과 동작 줄이기 설정의 초기 정지를 확인했다. 데스크톱·모바일 스크린샷을 검토했고 페이지 오류는 없었다. PNG의 투명도·캔버스·발 기준선·시트 영역 일치와 ZIP 내 키·원본 사진 제외도 확인했다. RN 앱에서 검증한 결과는 아니다.
- 체험 생성량 40단위에서 기준 캐릭터 요청 20단위, 동작별 1단위씩 총 23단위가 차감됐고 17단위가 남았다. 별도 결제나 충전은 하지 않았다. API가 보고한 유료 사용 시 참고 비용은 기준 캐릭터 $0.095, WALK 약 $0.04170, TAIL_WAG 약 $0.02869, SIT 약 $0.03024다. 이 값은 이번 시험의 실제 달러 청구액이 아니다.
- 작은 화면에서 읽기 쉬운 윤곽이 장점이다. 머리와 몸통 윤곽이 프레임마다 조금 달라지는 부분이 있어 초안으로 제공한다. 나머지 동작, 반복 연결의 최종 보정, 여러 방향과 RN에서의 실제 재생 검수는 남아 있다.
- 키는 Git에서 제외한 `backend/.env.pixellab`에 보관한다. 사진·생성 요청 원문·키는 프론트 전달 ZIP에 넣지 않는다. 이 시험은 생성 업체 비교이며 Spring Boot API 연결이나 서비스의 생성 업체 변경을 완료한 것은 아니다.

참고: [PixelLab 공식 API 명세](https://api.pixellab.ai/v2/openapi.json), [계정·API 키 설정](https://pixellab.ai/account).

## OpenAI 동작 비교 시험 · 2026-09-23

- 기존 OpenAI 기준 캐릭터를 입력으로 사용했다. `gpt-image-2`, 중간 화질, 1536×1536에서 WALK·TAIL_WAG·SIT의 3×3 프레임 시트를 각각 한 번 생성했다. 설치된 imagegen CLI로 실제 OpenAI Images API를 호출했다. 이 단계의 입력은 기존 도트 PNG이며 원본 사진을 다시 보내지 않았다.
- 생성 시간은 WALK 42.5초, TAIL_WAG 48.5초, SIT 40.5초였다. 실제 토큰 사용량과 청구액은 CLI에서 보존하지 않으므로 미확인이다. 기준 이미지의 1024×1024 출력 비용을 이 시트의 비용으로 재사용하지 않는다.
- 단색 배경과 가장자리 잔색을 로컬에서 제거하고, 512×512 칸을 같은 비율인 1/8로 축소해 64×64 투명 프레임 27장을 만들었다. 프레임별 크기를 따로 맞추지 않고, 발 기준선만 y=60으로 정렬했다. 첫 프레임도 생성 결과를 보존했으며 기존 기준 PNG로 덮어쓰지 않았다.
- 업체별로 동작 3종·9프레임, WALK/SIT 125ms·TAIL_WAG 160ms를 맞췄다. PixelLab과 동시에 재생하는 비교 화면에 동작 전환, 느리게 보기, 일시정지와 다시 보기를 넣었다. SIT는 두 결과 모두 마지막 자세를 유지한다.
- 앱 내 브라우저에서 두 캐릭터의 프레임 진행·동기화, 동작 전환, 느린 재생 선택, 일시정지 유지, SIT의 마지막 프레임과 다시 보기를 확인했다. 화면도 캡처해 검토했다. PNG의 투명도·크기·발 기준선, 시트와 프레임 일치, ZIP 내 키·입력 이미지 제외를 검사했다. RN 통합 검증은 아니다.
- 이번 샘플에서 OpenAI는 털의 질감과 명암을 더 많이 보존했다. 프레임마다 얼굴·털 무늬가 변하고, TAIL_WAG에서 몸과 발도 조금 움직여 추가 정리가 필요하다. 한 사진의 시험 결과이며 업체 전체의 품질을 확정한 비교는 아니다.
- OpenAI 결과: `output/imagegen/openai-tan-puppy-motions-v1/`. `openai-dog-sample.zip`에는 PNG 27장·스프라이트 시트·재생 정보·프롬프트·비교 미리보기가 있다.
- 두 업체 비교: `output/imagegen/dog-motion-comparison/preview.html`. `openai-vs-pixellab-assets.zip`은 두 업체 에셋을 함께 묶었다. 기존 로컬 미리보기 주소에도 같은 비교 화면을 반영했다. 기존 PixelLab 단독 화면은 `pixellab-only-preview.html`로 보존했다.

B-15는 전체 8종 동작과 서버 연결 검증이 남아 있어 `진행 중`이다.
