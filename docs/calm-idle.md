# B-48 · 쉬기와 꼬리 흔들기 구분

실제 검증 개체 `442418202600971`의 IDLE에서 앞·옆 꼬리가 반복적으로 크게 움직였다. 기존 생성 지시에는 `still tail`이 있었지만 검수에서 이 차이를 잡지 못했다. 일부 꼬리 자세 공통 문구에는 IDLE에서도 `wag laterally`가 들어갈 수 있었다.

## 다음 생성에 적용하는 기준

- IDLE은 제자리의 작은 호흡·눈 깜빡임이다. 꼬리는 승인된 방향별 기준 이미지의 위치·형태를 유지한다. 숨겨진 꼬리를 머리 위에 새로 그리지 않는다.
- IDLE 전용 꼬리 자세 문구를 사용한다. TAIL_WAG의 옆으로 흔들기 지시를 상속하지 않는다.
- 서버와 CLI가 같은 `quality-rules.json` v5를 사용한다. `IDLE_MOTION`은 IDLE에만 적용하며 걷기·꼬리 흔들기에는 넘길 수 없다.
- 승인된 **해당 방향** 이미지와 각 프레임의 불투명 영역을 양방향 비교한다. 1픽셀 이내 변화는 허용하고, 그 바깥으로 늘어나거나 사라진 영역이 3픽셀 이상이면 자동 불합격이다. 원본 0–8 프레임을 모두 검사한다.
- 윤곽 안에서만 일어나는 반복적인 꼬리 흔들기는 Luna 검수 지시에 추가했다. 도형 검사는 꼬리 위치 추정기가 아니며 색만 바뀌는 움직임을 탐지하지 않는다. 실제 AI의 판단 정확도를 보장하지 않는다.
- 불합격은 기존 최대 2회 재생성과 검토 보류 경로로 보낸다. 접수 이력·원본·비용 기록을 보존하고 예산을 재설정하지 않는다. 기존 작업의 규칙 해시를 조용히 덮어쓰지 않는다.

## 실제 수정본과 서버 원본의 구분

현재 미리보기의 IDLE 4방향은 승인된 기준 이미지의 꼬리와 붙어 있는 부위를 각 방향별 검토 마스크로 고정했다. 마스크 밖의 얼굴·몸·다리 픽셀은 모든 프레임에서 원본 그대로이며, 32×32·9프레임·140ms를 유지한다. 걷기·앉기는 변경하지 않는다. 이 마스크는 해당 강아지 전용이며 다른 강아지나 서버 자동 처리에 적용하지 않는다.

수정에 새로운 유료 이미지 요청은 사용하지 않았다. 원래 시트와 DB·Storage·검토 상태는 그대로 보존했고, 현재 미리보기만 별도 수정 PNG를 읽는다. 수정본을 서버 원본이나 최종 승인본으로 표시하지 않는다. 원본은 앞 6개, 뒤 3개, 왼쪽 7개, 오른쪽 5개 프레임에서 새로운 IDLE 윤곽 검사를 통과하지 못한다. 수정 후 앞·왼쪽·오른쪽은 이 검사를 통과하지만 **뒤의 몸 움직임 3프레임은 여전히 기준을 넘는다**. 요청한 꼬리 고정 외의 몸 움직임을 임의로 변경하거나 최종 승인하지 않았다.

## 검증

- `backend/scripts/fixtures/idle-motion-alpha.json`: 실제 생성된 네 방향 원본의 36프레임 불투명 영역과 PNG SHA. 사진·비밀 값 없음.
- Python과 Java가 같은 실제 결함 프레임을 판정한다. 잘못된 AI 통과를 도형 검사가 뒤집으며 원본 픽셀은 수정하지 않는다.
- 1픽셀 호흡·색 변화 허용, 꼬리 수축 감지, 다른 행동 제외, 방향별 기준 이미지 선택, 전체 프롬프트 길이 및 첫/마지막 프레임 계약 검사.
- 새 `IDLE_MOTION` 판정이 해당 시트만 보완하고 이전 영수증을 남기는 PostgreSQL 통합검사. AI와 PixelLab 모의 응답을 사용하며 유료 생성 품질 검증을 의미하지 않는다.
- API·DB 스키마·환경변수 변경 없음. 배포 여부와 실제 검사 결과는 PR 병합 기록에 기재한다.

노션 새 카드·외부 기록은 이전 자동 승인 검토의 거절에 따라 별도 승인 대기 상태를 유지한다.
