# B-101: 실제 초안의 문장 편집으로 글자 한도 복구

- 선행: B-100 / PR #112 / `5f88e2a` 배포, 같은 비공개 10마리 배치.
- 브랜치: `backend/b-101-prompt-length-editing`.
- 노션: 연결 도구 미제공으로 카드 미동기화. 실제 PR·검증 결과를 별도 기록한다.

## 문제와 결과

B-100의 몇 가지 동등 표현 치환은 1016자 초안에는 맞았지만, 같은 배치의 다른 북쪽 쉬기 초안은 1139·1071·1068자로 여전히 실패했다. 생성 사진이나 시각 검수 문제가 아니라 PixelLab 제출 전 문구 형식 오류였다.

v7은 기존 공백·동등 표현 복구로도 해결되지 않는 **완료된 길이 초과 초안**에 한해 Luna가 최대 두 번 문장 편집을 제안하게 한다. 매번 전체 기본 지시와 모든 원본 학습 규칙, 현재 문장, 실제 길이와 필요한 감소량을 전달한다. 개수 제한으로 규칙을 골라내지 않는다. 중복 조건을 같은 의미의 짧은 표현으로 병합하도록 요청한다.

서버가 각 교체 범위의 정확한 일치·유일성·비중첩·길이 감소를 검증한다. 빈 교체, 전체 문장 교체, 모호한 일치, 확장은 거부한다. 모든 교체는 편집 전 문장의 위치를 기준으로 적용한다. 결과의 허용 문자·완결 문장·실제 글자 수가 맞아야 기존 독립 의미 관찰과 이미지 접수로 진행한다. 여전히 길거나 편집이 잘못되면 원문과 편집 시도 기록을 남기고 실패한다. 문자열을 잘라서 통과시키지 않는다.

편집기 입력에도 **전체 규칙**이 전달되며, 편집 뒤 기존 검증기가 기본 지시와 전체 규칙을 다시 대조한다. WARN_ONLY는 의미 지적을 경고로 남기고, 엄격 정책은 의미 검사 통과를 요구한다. 새 편집기가 의미 보존을 수학적으로 보장하는 것은 아니다. 원문, 제안, 적용 여부, 길이, 해시, 의미 판정을 모두 기록한다. 추가 호출은 텍스트 편집 최대 2회이며 이미지 재생성 예산을 늘리지 않는다.

긴 작성 후 편집 단계에 들어가기 전 현재 소유자·아직 유효한 작업 잠금·입력 해시·전체 규칙·이용 허가를 재확인하고 잠금을 5분 갱신한다. 만료/이전 소유자는 갱신하지 못한다. 두 편집 호출과 독립 관찰은 최대 60초 호출 3회 범위다. 저장과 공급자 접수에서도 기존 권한·잠금 검사를 유지한다.

## 기존 작업 재개

기존 담당자 `/prompt-resume`에 v6 및 v6/WARN_ONLY의 명확한 제출 전 실패를 추가한다. 최신 실패 입력·4방향 시드·규칙 해시, 기존 승인, 권한, 공급자 영수증·예약 부재와 버전당 1회 조건을 유지한다. 기존 완료 이미지·승인·보완 횟수·과거 실패 기록을 보존한다. 현재 v7 실패를 반복 재개하도록 허용하지 않는다.

API 본문, 환경변수, DB V24, 이미지 품질 규칙 v43은 변경하지 않는다. Swagger 설명의 구버전 허용 범위만 갱신한다.

## 실제 Luna 재현

`backend/scripts/fixtures/prompt-length-edit-v7/`에 자격 증명·사진 URL 없는 실제 실패 및 편집 결과를 남겼다. 연결된 `gpt-5.6-luna`로 네 완료 초안을 각각 실행했다. PixelLab 이미지는 추가 구매하지 않았다.

| 입력 길이 | 결과 길이 | 편집 호출 | 독립 의미 관찰 |
| --- | --- | --- | --- |
| 1139 | 990 | 1 | 학습 규칙 11개 보존, 기존 초안의 팔레트·crown 금지 누락 2개 경고 |
| 1071 | 991 | 2 | 기본 조건과 학습 규칙 11개 보존 판정 |
| 1068 | 959 | 2 | 기본 조건과 학습 규칙 11개 보존 판정 |
| 1016 | 961 | 1 | 기본 조건과 학습 규칙 11개 보존 판정 |

이는 문구 편집/관찰 결과이며 실제 이미지 품질 판정이 아니다. 네 사례 성공이 모든 미래 문구의 성공을 보장하지 않는다. 배포 후 기존 작업 재개와 10마리 전체 완료는 별도로 확인한다.

## 검증

- 실제 실패 초안과 실제 편집 제안 회귀 재생, 모호·중첩·확장·빈 편집·형식 위반 거절, 2회 한도, AI 시간 초과 기록.
- 초기 작성/보완 공통 경로, 전체 원문 독립 관찰과 WARN_ONLY의 부정 판정 보존.
- PostgreSQL: v6 재개 시 기존 결과 보존, 중복/현재 버전/유료 접수/권한 불일치 거절, 편집 단계 잠금 갱신의 소유권·만료·입력·허가 검증.
- 단위·통합·패키징 및 CI 실제 결과는 PR에 기록한다. 배포와 실제 10마리 전체 완료는 아직 확인 전이다.
