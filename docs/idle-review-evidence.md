# B-58 · 가만히 쉬기의 명암 변화를 큰 자세 변화로 오판하는 문제

브랜치 `backend/b-58-idle-review-evidence`. B-57 실제 배포 검증 후속. 노션 쓰기는 앞선 자동 승인 검토 거절로 미동기화이며 재시도하지 않았다.

## 실제로 발견한 문제

강아지 `442418202600971`의 B-57 서버 보완에서 왼쪽 쉬기·걷기·앉기는 통과했으나, 뒷면 쉬기를 Luna가 `DISCONTINUITY` / `IDLE_MOTION`으로 거절했다. 원본에는 6–8번 프레임의 크기 확장, 복원본에는 서기/웅크리기 변화를 보고했다.

실제 원본과 복원본 18프레임을 확인한 결과 각각의 9개 알파 마스크와 바운딩 박스는 완전히 동일했다. 보이는 픽셀의 첫 프레임 대비 RGB 채널 최대 차이는 원본 17/255, 복원본 15/255였다. 작은 명암 변화만 있고, 보고된 큰 크기·윤곽 변화는 없었다. 이는 큰 동작이 남은 종전 실패와 구분해야 한다. 기존 실패 판정은 수정하거나 삭제하지 않았다.

원본 PNG·복원 PNG·실제 Luna 응답·해시·측정값은 `backend/scripts/fixtures/idle-review-evidence.json`과 `idle-review/`에 보존한다. 인간의 시각 판단과 서버의 실패 판정은 별도 필드이며, 자료를 넣는 것만으로 승인하거나 긍정 학습 사례를 등록하지 않는다.

## 변경

- 검수 요청마다 정확한 9프레임의 알파 변화 수, 투명 영역을 제외한 RGB 채널 차이, 경계 상자를 계산한다. 첫 프레임 및 직전 프레임과 비교하며 마지막 8번 프레임도 포함한다.
- 이 측정값과 방향별 기준 도트가 시간 순서의 프레임이 아니라는 설명을 Luna에 함께 전달한다. 검수 보고서에도 `pixelEvidence`로 남긴다.
- 모든 알파가 같고 보이는 채널 차이가 24 이하이면 작은 명암 변화라는 참고 정보를 제공한다. 이를 이유로 AI 실패를 지우거나 자동 통과시키지 않는다. 내부 눈·무늬·방향 결함은 별도 검수한다. 큰 내부 색 변화나 같은 경계 상자 안의 알파 변화도 구분한다.
- CLI 하네스도 동일한 측정값을 산출한다. 고정 잘림·꼬리·방향 검사, 보완 횟수, 원본/복원본 검수와 승인 조건은 유지한다.
- 명시적인 `quality-recheck`에서는 이전에 통과했던 동작이 새 판정으로 실패하더라도 남은 보완 예산을 사용해 이미지를 재생성하지 않는다. 저장된 원본과 실패 판정만 유지하고 담당자 검토에 남긴다. 일반 생성 작업의 자동 보완은 유지한다.

공통 규칙을 `sprite-regressions-2026-10-07-v10`으로 올려 기존 해시와 구분한다. 새 생성부터 검수 입력에 적용하며, 기존 완료된 미승인 팩은 담당자용 `quality-recheck`로 저장된 이미지만 재검수한다. PixelLab 재생성·예산 초기화·새 권한·DB 마이그레이션·API 요청 변경은 없다. 규칙 해시가 다른 학습 문구는 기존 범위 검사에 따라 그대로 자동 적용하지 않는다.

규칙 SHA: `7596b2ccbe0383f08190d6623683599fbdec6d279911568d979dc2248f14fc79`.
