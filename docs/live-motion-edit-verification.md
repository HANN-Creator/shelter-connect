# B-56 실제 편집 결과의 성공·실패 회귀 검증

B-54/B-55의 새 요청 빌더로 실제 PixelLab `edit-animation-v2`를 세 번 호출했다. 배포 대기 중인 코드를 로컬에서 실행한 제한된 비교이며, Render 워커·DB·Luna 재검수의 종단 검증은 아니다. 기존 서버 작업의 이미지·보완 횟수·정책·승인 상태는 변경하지 않았다.

| 동작 | 보완 전 | 편집 원본 및 색상 복원 후보 | 시각 확인 |
| --- | --- | --- | --- |
| 정면 IDLE | IDLE_MOTION | 픽셀 검사 통과 | 머리 위 움직이는 돌출부가 없어지고 서 있는 자세 유지 |
| 왼쪽 WALK | 가장자리 접촉 | 0부터 센 2–8번 프레임 접촉, 계속 실패 | 꼬리가 들리고 가장자리에 닿는 문제 유지 |
| 왼쪽 SIT | 가장자리 접촉 | 0부터 센 2·4·5·6번 프레임 접촉, 계속 실패 | 바깥으로 뻗은 꼬리는 줄었으나 일부 여백 문제와 꼬리 형태 변화가 남음 |

원본·편집 원본·복원본의 81프레임 알파와 PNG 해시를 기존 `idle-motion-alpha.json`, `tail-repair-alpha.json`, `sit-tail-alpha.json`에 보존했다. 이 fixture들은 기존 `quality-rules.json`의 회귀 목록에 등록되어 있다. 검사 기준 자체는 변경하지 않아 v9/SHA `6fae1b5ad7b062411172441cc8ac9eb6ec11c6cef905f6c1a0dd4c35014100ec`와 기존 활성 학습 규칙을 유지한다.

회귀 검사는 정상 IDLE을 오탐하지 않는지, 실패한 편집 원본과 복원본을 모두 계속 거부하는지, WALK의 실제 마지막 프레임 8도 검사하는지 확인한다. 알파 검사는 눈·외형·꼬리 형태에 대한 시각 검증을 대신하지 않는다. 정면 IDLE도 Luna 재검수와 최종 승인은 남아 있다.

실제 응답에 기록된 사용량은 호출당 `generations: 20`, 세 호출 합계 60이다. 이번 결과의 관측값이며 모든 모델·요청의 고정 가격으로 일반화하지 않는다. 실패 요청 재제출과 추가 생성은 하지 않았다.

새 편집 방식으로 모든 불량이 해결된 것은 아니다. 현재 IDLE 개선 사례 한 건을 확인했으며, WALK/SIT은 추가 보완 방법 검토가 필요하다. 원본을 자르거나 마지막 프레임을 숨기거나 축소해서 성공으로 바꾸지 않았다. 서버의 기존 REVIEW 결과와 자동 학습 상태도 덮어쓰지 않았다.

이번 변경은 검증 fixture·테스트·문서만 추가한다. API·DB·환경변수·런타임 동작 변경은 없고, 이 기록 자체를 위해 서버를 재배포할 필요는 없다. B-54/B-55의 워커 변경 배포와 서버 실제 검증은 별개로 남아 있다. 노션은 앞선 외부 쓰기 제한으로 미동기화다.
