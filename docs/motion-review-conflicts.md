# B-73 동작 검수 충돌 후속 검증

PR #86과 같은 검수 완료 기준에 포함한다. 새로운 그림체/동물 생성 작업이 아니다.

## 수정한 계약

- 40px 검수는 승인 씨앗/첫 프레임의 **외형·진입 자세**와 실제 프레임 0–8의 **시간 변화**를 별도 이미지로 본다. 기준 씨앗을 프레임 사이에 반복해 보행처럼 보이게 하지 않는다. 원본과 마지막 프레임을 보존한다.
- 첫 프레임 RGBA 완전 일치는 `firstFrameUnchanged` 진단으로 남는다. 자동 승인에는 `motion-observation-tristate-v3`의 진입 자세 PASS, 씨앗 해시, 실제 검수한 9프레임 해시, 현재 규칙 해시가 모두 필요하다. 실제 외형·자세 불일치를 색상 허용으로 우회하지 않는다.
- 불명확/실패 관찰은 같은 원본으로 1회 독립 재관찰한다. 이전 판정을 전달하지 않는다. 속성별 불일치와 불확실은 `UNCERTAIN`으로 보존한다. 이 상태는 유료 편집·실패 학습·추가 학습 보완·최종 공개를 차단한다. 저확신을 외형 결함으로 바꾸지 않는다.
- 한 가지 제한된 예외: 첫 관찰이 **보행만** 주장하고, 독립 관찰은 모든 속성 PASS 및 STILL/BREATH_BLINK이며, 하단 1/3에서 전 프레임 알파 변화 0 / 어두운 윤곽 변화 최대 1px이면 그 보행 주장을 해소한다. 그 외 속성이나 구조 검사 실패를 해소하지 않는다. 두 관찰 모두 보행을 주장해도 위 측정과 충돌하면 확정 불량 대신 보류한다. 어두운 윤곽은 RGB 각 채널 <100인 픽셀을 뜻하며, 이 보조 측정은 다리/꼬리 의미 분할이 아니다.
- v24는 색상만 FAIL인 첫 관찰과 독립적인 전체 PASS 사이에서도 실제 RGB 분포를 확인한다. 전 프레임을 frame0 및 직전 프레임(8→0 포함)과 비교한 18쌍 모두에서 중앙값 0, 90백분위 ≤ 기존 작은 명암 기준 24, 95백분위 ≤ 기존 독립 명암 검사 기준 64를 요구한다. 중첩된 불투명 픽셀만의 색 분포이므로 알파·눈·외형·꼬리·구조 검사를 대신하지 않는다. 동반 결함, 합의된 색상 실패, 큰 색상 변동은 이 예외로 통과시킬 수 없다.
- 고정된 알파/바운딩 박스만으로 정지 상태를 확정하지 않는다. 꼬리 내부 윤곽·얼굴·털 무늬·색 깜빡임은 계속 검사한다. 걷기, 앉기, 눕기 등 다른 행동에 IDLE 전용 예외를 적용하지 않는다.
- 원본 편집 시트와 선택 시트가 같은 바이트이고 새 검수 버전이면 1개의 검수 결과를 공유한다. 다른 바이트는 둘 다 검사한다. 기존 32px 작업의 고정된 원본/복원본 이중 검사 계약은 유지한다.
- 보완 요청이 이미 실패한 첫 프레임을 무조건 그대로 보존하라고 하지 않도록 수정했다. 확인된 자세 결함일 때만 첫 프레임도 고치도록 하며 예산을 늘리지 않는다.

API/DB/환경변수 변경 없음. 기존 작업은 규칙 해시에 고정되며 자동으로 이전 결과를 새 승인 증거로 바꾸지 않는다. 규칙 변경 후에는 기존 명시적 재검수 경로를 사용한다. B-73의 중단된 부분 생성 체크포인트와 누적 비용/횟수는 그대로 남겼으며, 이 PR에서 SQL로 초기화하거나 새 작업으로 우회하지 않는다.

## 실제 비교 기록과 한계

`backend/scripts/fixtures/motion-review-v22/`에 원본 해시, 이전 보고서, 사전 비교 계획, 실제 응답을 보존한다. 직접 확대 확인한 에이전트 라벨이며 독립적인 사람 정답이나 전체 강아지의 정확도 지표가 아니다.

v22 실제 비교에서는 앞/옆 IDLE와 기존 WALK가 PASS, 마지막 프레임 가장자리 픽셀·고정 시트를 WALK로 지정한 경우·마지막 프레임 얼굴 색상 변화는 모두 차단됐다. 처음에 정상으로 분류했던 북쪽 IDLE도 차단되어 첫 실행의 정상 기대 assertion은 2/3으로 실패했다. 확대 확인에서 말린 꼬리의 내부 끝부분/윤곽과 색이 실제로 변했으며, 독립 관찰 둘도 같은 결함을 기록했다. `adjudication.json`에 초기 라벨의 오류와 근거를 명시했다. 원래 계획·실패·이미지·응답은 삭제하지 않았다. 이 수정 후의 결과를 처음부터 독립 검증에 성공한 것처럼 표현하지 않는다.

이후 배포 JAR의 실호출에서 옆 IDLE가 보행 FAIL/정지 PASS로 엇갈려 `UNCERTAIN`으로 보류됐다. 코드가 유료 수정·부정 학습으로 오판을 증폭하지 않은 것은 확인했지만 정상 통과 기준은 실패했다. v23은 이 재현을 근거로 하단 윤곽 측정과 보행 주장에 한정된 독립 검수 해소를 추가한다. 새로운 실제 비교 결과는 PR과 아래 실행 기록에 추가한다. 이전 실패를 재호출로 덮어쓰지 않는다.

v23 패키지는 옆 IDLE의 보행 오판이 사라졌지만, 색상 FAIL/PASS 불일치로 여전히 보류됐다. 얼굴·외형·꼬리·발·방향·진입 자세·연속성은 두 관찰 모두 PASS였다. 원본의 보이는 픽셀을 측정하면 frame0 대비 RGB 변화의 중앙값은 모든 프레임에서 0, 90백분위는 최대 18이었다. 이 결과를 바탕으로 v24에 위 색 분포 입력과 제한된 독립 검수 해소를 추가했다. v22/v23의 실패 응답과 JAR 해시는 보존한다. 정상 라벨을 바꾸거나 동물을 새로 생성해 검증을 피하지 않았다.

## 전체 생성 상태

원격 DB·이미지·누적 보완 예산은 변경하지 않았다. 실제 기본 도트 자동 승인/저장까지 성공한 이전 로컬 패키지 실행은 계속 중단 상태다. IDLE 북쪽의 실제 꼬리 움직임/색 깜빡임과 아직 생성되지 않은 WALK/SIT 8개 때문에 **전체 12개 동작 생성·최종 공개 완료를 의미하지 않는다**. 이 문서의 검수 실호출과 로컬 PostgreSQL의 모의 공급자 기반 승인 통합 검사는 구분한다. B-68의 전체 팩 품질 검증과 배포 후 실제 서버 확인은 별도로 남는다.
