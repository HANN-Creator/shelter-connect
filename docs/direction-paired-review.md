# B-59 · 같은 방향의 원본 프레임을 나란히 비교하는 검수

브랜치 `backend/b-59-direction-paired-review`. B-58 실제 배포 검증의 후속이며 노션 쓰기는 앞선 자동 승인 검토 거절로 미동기화다.

## 실제 확인한 결과

B-58 배포 후 같은 비공개 개발 팩의 저장된 12개 동작을 재검수했다. 걷기·앉기 8개는 통과했지만 쉬기 4개는 `IDLE_MOTION`으로 남았다. 새 PixelLab 요청은 0건이고 승인 기준 도트, 108프레임, 편집 원본, 보완 횟수는 모두 그대로였다. 종전 11/12 통과는 v9 판정이며 최신 v10 결과는 8/12다. 이전 실패·정상 보고서는 추가 전용 이력에 보존했다.

뒷면 쉬기 복원본 자체는 통과했지만 편집 원본에서 꼬리 움직임을 보고했다. 원본 9프레임의 알파는 동일하며 첫 프레임 대비 RGB 최대 변화는 17/255다. 정면 원본은 49/255, 복원본은 55/255까지 색 변화가 있어 `subtleShadingOnly=false`지만, 이 불리언 자체는 큰 자세 변화가 있다는 뜻이 아니다. 원본·복원본과 실제 실패 보고서를 `backend/scripts/fixtures/idle-review-recheck.json`에 보존한다. 이 자료가 AI 통과나 승인으로 바뀌지는 않는다.

[OpenAI 공식 이미지 가이드](https://developers.openai.com/api/docs/guides/images-vision)는 세밀한 공간 판단, 잘못된 설명, 이미지 크기 조정의 한계를 명시한다. 여러 방향 기준 이미지와 떨어진 프레임 배치가 혼동을 키울 수 있다는 것은 이번 변경의 가설이며, 실제 오판의 확정 원인이나 수정 성공으로 단정하지 않는다.

## 변경한 검수 입력

- 상단에는 검사 중인 방향의 승인 기준 도트만 보인다.
- 아래 9쌍은 각각 왼쪽에 같은 첫 프레임, 오른쪽에 0–8번 검사 프레임을 보여준다. 모두 32×32 전체 캔버스를 같은 4배 최근접 확대한다.
- 프레임 번호와 기준 표시를 구분한다. 원본 한 픽셀은 표시된 네 픽셀이라는 점, 작은 명암 변화와 눈 깜빡임의 큰 RGB 차이는 그 자체로 결함이 아니라는 점을 명시한다.
- 같은 실제 픽셀 측정값과 모든 잘림·꼬리·방향·눈·동작 검사를 유지한다. 모델 응답을 강제 통과시키거나, 재호출로 통과할 때까지 반복하지 않는다. 모델 및 호출 횟수는 바꾸지 않는다.
- 보고서에는 `reviewLayout=matched-direction-frame-pairs-v1`을 기록한다. 기존 학습 제안·블라인드 검증용 보드는 자체 배치와 지침을 유지한다.

공통 규칙 v11, SHA `b33d5a540b1d5adbec62438e29fea781fb13bd0b0c525b043ae476dc6068da8b`. 기존 v10 학습 문구는 다른 규칙 해시이므로 자동 재사용하지 않는다. API 요청·DB·환경변수·보완 예산·저장된 이미지 변경은 없다.

## 검증과 남은 범위

Java 회귀 검사에서 네 방향 기준 선택, 모든 9프레임의 전체 캔버스와 4배 확대 픽셀, 마지막 프레임, 원본 바이트 보존을 확인한다. 알려진 실제 잘림과 AI 실패는 계속 차단한다. Python 하네스는 네 방향 실제 재검수 자료의 해시·픽셀 측정과 기존 실패 판정 보존을 검사한다.

실제 v11 Luna 판단은 배포 후 확인해야 한다. 현재 서버 작업은 `REVIEW / QUALITY_REPAIR_EXHAUSTED`이며 팩 승인은 하지 않았다. 프론트는 정확한 v10 서버 파일과 `서버 8개 통과 · 쉬기 4방향 재검수 대기`를 표시한다. 이번 코드의 오프라인 검사와 기존 v10 실서버 결과를 구분한다.

## 배포 후 실제 결과

v11 재검수는 7/12 통과다. 정면·뒷면 IDLE 원본/복원본은 통과했고, 좌우 IDLE과 SIT 정면·뒷면·왼쪽은 실패했다. PixelLab 추가 요청 0회, 도트/108프레임/보완 횟수/과거 이력은 동일하다. 임시 STAFF와 로그인은 해제했고 프론트는 최신 7/12 상태로 갱신했다. 전체 승인하지 않았으며 [B-60의 동작별 검수 및 기존 쉬기 보완](idle-continuation-fallback.md)으로 이어간다.
